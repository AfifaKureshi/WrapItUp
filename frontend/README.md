# PackWise Flutter client

This client is a responsive Material 3 application for SIH PS 236. It includes role-specific navigation and dashboards for farmers, manufacturers and researchers, multilingual navigation/product prompts (English, Hindi, Gujarati and Marathi), voice input for the product problem, secure session storage, offline project snapshots, PDF/CSV saving, QR batch records, sensor and datasheet uploads, trial/review workflows, and the optional trained-model status screen.

## Start

From this directory, generate the platform runners once with a locally installed stable Flutter SDK:

```bash
flutter create --project-name packwise --org com.packwise .
flutter pub get
flutter run -d chrome --dart-define=API_URL=http://localhost:8000
```

For an Android emulator use `--dart-define=API_URL=http://10.0.2.2:8000`. For a physical device replace the host with the computer's LAN IP and allow that origin in the backend `CORS_ORIGINS` setting.

The runtime used to prepare this package did not include Flutter itself, so platform runner files are intentionally generated by `flutter create` on the developer machine. The Dart source and dependency manifest are complete.
